Welcome to the TRsync Setup Wizard

TRsync is a native, fast, and feature-rich graphical user interface for rsync, designed for Q4OS / Trinity Desktop Environment (TDE).

Key Features:

  • Profile Management: Unlimited named session profiles and session sets for automated batch syncing.
  • Simulation (Dry-Run): Test synchronization safely before writing any files.
  • Client-Side Encryption: Transparent encryption and decryption of backups via gocryptfs or EncFS.
  • One-Click Restore: Invert sync direction with automated FUSE decryption.
  • Real-Time Monitoring: Live progress indicators, decoupled RAM output buffering, and detailed log auditing.
  • Trinity Integration: Native tdesudo superuser support and size-optimized standalone binary.
